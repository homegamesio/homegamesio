Why build on Homegames?

Multiplayer built in

Homegames handles all the networking. Your game code runs on the server, clients connect via WebSocket. No socket code to write.

Browser-based studio

Write code, manage assets, preview live, and publish — all from the browser. No local setup required.

Simple JavaScript API

Games are plain JavaScript classes. Define shapes, text, and assets with SquishJS. No game engine to learn.

No strings attached

No email required to sign up. No fees. No ads. Set a BTC address on your profile if you want to accept tips.

Open Source

Homegames has been in development as a side project since 2018. All platform code and all published games are GPLv3. Contributions welcome.
