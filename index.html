Host It Yourself

Run Homegames on a machine in your house. Download, extract, and launch — Node, Git, and Docker are not required. Supports Windows x64, macOS (Apple Silicon or Intel), and Linux x64. Everyone on your network plays in their browser.

Open Source

  • Everything is GPLv3 from the platform code to the games to this website. You can read the code and fork it if you want to.
  • Self-host on your own hardware. Homegames was designed to be self-hostable, including the API. See the self-hosting guide.
  • Preservation. If this website gets hit by a bus, your games can live on.
